# Cookie Clicker Lite

A lightweight, browser-based clicker game inspired by Cookie Clicker.

## Features

- Manual cookie clicking with scaling click power.
- Building shop with escalating costs and passive cookie generation (CPS).
- Unlockable upgrades that improve click power and production.
- Golden cookie events with temporary frenzy boosts or instant rewards.
- Achievement system.
- Prestige/ascension system with permanent production bonuses.
- Auto-save and manual save using `localStorage`.

## Run

Open `index.html` in any modern browser.
